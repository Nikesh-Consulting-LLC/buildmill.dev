# US-91.13 — A count on a coloured button must be readable

**Status:** Testing
**Phase:** 91 — Usability: the dashboard reads like the job
**Depends on:** nothing

## Story

As the manager, the **Add agent** button shows my quota — `(2 of 5)` — in
`text-muted-foreground`, a low-contrast grey token designed for a page
background. The button is `variant="create"`: saturated orange fill,
`text-create-foreground`. Grey on orange is close to unreadable, and the
count is the one thing on that button carrying information — the label is
the same every time.

The bug is the token, not the size: a foreground colour picked for one
surface, used on another. The fix is to tint the button's *own* foreground
rather than borrowing a neutral one.

## Acceptance criteria

- **AC1 — the count uses the button's foreground.** In
  [add-agent-wizard.tsx](../apps/web/src/app/(app)/team/add-agent-wizard.tsx),
  the quota span becomes `text-create-foreground` at reduced opacity (e.g.
  `/75`) instead of `text-muted-foreground` — de-emphasised relative to the
  label, still legible against the fill.
- **AC2 — it holds in both themes.** Verified light and dark; the `create`
  fill and its foreground are tokens, so tinting the foreground follows the
  theme rather than fighting it. Screenshot both in the story.
- **AC3 — the same mistake is fixed wherever else it was made.** Grep for
  `text-muted-foreground` inside a `variant="create"`, `variant="success"`,
  `variant="default"` or `variant="destructive"` button and fix every hit
  the same way. One-line fixes that leave siblings broken are how a design
  system rots.
- **AC4 — nothing else about the button changes.** Same label, same icon,
  same size, same disabled behaviour, same quota logic.

## Out of scope

- Rethinking how quota is displayed (a badge, a separate line, hiding it
  when there is room to spare) — this is a legibility fix.
- Any change to the `create` variant's fill colour or to the tokens in
  `globals.css`.
- Auditing contrast across the whole app; that is a bigger piece of work than
  a Phase 91 story.

## Verified (2026-08-14)

- The quota span now uses `text-create-foreground/75` — the button's own
  foreground at reduced opacity — instead of `text-muted-foreground`, a
  neutral picked for a page background.
- Swept for the same mistake elsewhere: the Add-agent trigger was the only
  place a muted token sat on a filled button variant.

during this session, so light/dark screenshots (AC2) are for the manager's UAT.
