# US-82.4 — Adopt untracked tests

**Status:** Testing
**Phase:** 82 — Smoke, conversion, selection
**Dependencies:** us-81.4

## Story

As a manager, I want tests that exist in the repo but not in the case
library to be visible after every suite run and adoptable in one click, so
the library converges on what the suite actually runs instead of drifting
away from it.

## Context

us-81.4 made the one-way mapping honest: a case whose spec vanished blocks.
This story closes the drift in the other direction — specs that exist with
no case. Between them, `(suite_id, spec_ref)` stays a two-way truth.

## Acceptance criteria

1. The suite run view lists results with no matching case as **Untracked**,
   with their `spec_ref`, status, and duration.
2. Each untracked row (and a select-all) offers **Adopt**: creates a
   `test_cases` row with `execution='automated'`, the `suite_id` and
   `spec_ref`, `source='human'` (a manager's click is the author), and a
   title derived from the `spec_ref` (editable immediately).
3. From the next run on, adopted cases match and receive results like any
   automated case; on the next release cut they inherit like any case.
4. Already-adopted specs never show as untracked again; renaming a spec
   shows the old case unmatched (us-81.4's strictness) and the new ref
   untracked — adopting the new one and abandoning the old is the documented
   path.

## Out of scope

- Auto-adoption without a click.
- Fuzzy matching of renamed specs to existing cases.

## Outcome

Built 2026-08-11, inside the suite run view: results with no matching case
list as **Untracked** with per-row Adopt — creates an automated case
(`suite_id` + `spec_ref`, `source='human'` because the manager's click is the
author, title derived from the spec_ref and editable in the library). Future
runs match adopted cases by the same `(suite_id, spec_ref)` the pipeline
already uses; a renamed spec shows old-case-unmatched plus new-ref-untracked,
exactly as specified.

**Verified:** build clean; the matching path is shared with 81.4's tested
mapping. **Not verified:** the adopt flow in a browser.
